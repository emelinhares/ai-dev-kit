# Working Templates

Copy only the template needed for the current task, then remove prompts that do
not apply. Completed durable knowledge belongs in its official human-document
home; transient task material may remain in the work system used by the adopted
project.

- [Project intake / product summary](project-intake.md)
- [Feature](feature.md)
- [Bug](bug.md)
- [Discovery](discovery.md)
- [Research](research.md)
- [Release](release.md)
- [Technical decision / ADR](../../docs/decisions/0000-template.md)
- [Project adoption templates](adoption/README.md)

Templates must not contain credentials, private keys, tokens, production
records, personal data, or raw research dumps.
