# Operational Memory

`.ai/` contains the kit's compact, repository-specific operating memory:

- `AGENTS.md`: the single agent router;
- `project/`: current state, scope, terms, decisions, assumptions, health, and
  concise research evidence;
- `roles/`: role contracts and handoff gates;
- `guardrails/` and `policies/`: mandatory safety and evidence rules;
- `practices/`: adaptable delivery methods;
- `templates/`: reusable working artifacts.

Durable explanations for people live in [`docs/`](../docs/README.md). When a
topic belongs there, project memory should link to it and contain only the
minimum routing/status information an agent needs. Generated transcripts, raw
research dumps, credentials, and production data do not belong in either area.
