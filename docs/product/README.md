# Product

**Accountable role:** Product owner  
**Review trigger:** Product outcome, target user, safety boundary, or operating
mode changes

## Summary

The AI Development Kit helps a non-technical product owner safely guide AI
collaborators through creating a new product or adopting an existing project.
The owner communicates in outcomes and trade-offs; one coordinator translates
that intent into evidence, decisions, delivery slices, verification, maintained
knowledge, and release gates.

## Users and needs

- A product owner needs a single plain-language collaborator, not a panel of
  technical roles to orchestrate.
- AI collaborators need compact, repository-owned memory and clear gates.
- Maintainers need durable, non-duplicated product, engineering, decision, and
  operational truth.
- Authorized operators need explicit targets, least privilege, rollback,
  observation, and approval for restricted actions.

## Capabilities

- `NEW_PRODUCT` discovery-to-release workflow
- `ADOPT_PROJECT` mapping, health, environment, access, and operability workflow
- Task/risk routing across defined role contracts
- Required official-source research for decision-sensitive uncertainty
- Adaptive testing, context management, and specialist delegation
- Safety gates for sensitive data, access, production, deployment, mutation,
  infrastructure/DNS, payments, paid services, and cost
- Canonical documentation and repository-specific operational memory

## Boundaries

The kit is technology-agnostic and does not supply project-specific commands,
credentials, production access, security certification, legal/privacy approval,
or authority to deploy. It supports decisions; it does not replace accountable
owners and authorized operators.

## Success

A product owner can state a problem plainly and receive a bounded recommendation
with evidence, risk, cost, acceptance, and the next meaningful choice. An
adopted repository develops its own glossary and verified map. Delivery does not
cross a restricted boundary without immediate explicit approval.
