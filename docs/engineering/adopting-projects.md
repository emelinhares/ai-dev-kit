# Adopting an Existing Project

**Accountable role:** Coordinator with mapper  
**Review trigger:** Adoption workflow or access classification changes

`ADOPT_PROJECT` is the conservative entry point for an existing or uncertain
repository. It lets the owner receive an evidence-based map, health summary, and
recommended next action before changes are proposed.

The canonical agent procedure is the
[adoption practice](../../.ai/practices/project-adoption.md); its
[adoption templates](../../.ai/templates/adoption/README.md) cover intake
artifacts without creating a second documentation tree. Completed current truth
is curated into the relevant product, engineering, or runbook home.

The product owner is asked for outcomes and material approvals, not credentials
or technical orchestration. Unknowns and conflicts remain visible until
evidence resolves them. Never store credentials, SSH private keys, tokens,
production records, or personal data.
