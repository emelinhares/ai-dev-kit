# Engineering

**Accountable role:** Architecture/engineering owner  
**Review trigger:** Repository structure, workflow contract, safety boundary, or
validation strategy changes

This section states current engineering truth:

- [Architecture](architecture.md)
- [Adopting an existing project](adopting-projects.md)

Historical rationale belongs in [ADRs](../decisions/README.md). Operational
steps belong in [runbooks](../runbooks/README.md). Working status belongs in
[`.ai/project/`](../../.ai/project/).

The kit intentionally defines no language, framework, cloud, database, CI, or
deployment command. An adopted repository documents its verified choices here
and preserves material choice history in ADRs.
